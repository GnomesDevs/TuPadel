# Web - Panel de Administración

Interfaz web del panel de administración para ayuntamientos y comunidades.

## Requisitos

- Docker Desktop

## Comandos para arrancar el proyecto

1. En la raíz del proyecto abre la terminal y ejecuta:

```bash
Copy-Item .env.example .env
```

2. Lanza el Proyecto: 

```bash 
docker compose up
```
